---
name: jd-to-project
description: >
  Transform a job description (JD) into a credible, interview-ready project that demonstrates the candidate's ability to perform the target role. Use when a user provides a job description and wishes to build a project to demonstrate the abilities required for the target position.
---

## steps:
### 1. jd_analysis
Analyze the job description to identify must-have skills and abilities. Extract what capabilities the position requires and how they should be demonstrated in a project context. reference_file: `references/jd-analysis.md`

### 2. open_source_research
Research relevant open source projects on GitHub related to the job. Analyze advantages and disadvantages of each project to learn from them. reference_file: `references/open-source-project-research.md`

### 3. project_design
Design a project that meets JD requirements while being innovative, showcase-worthy, and capable of rapid dissemination. reference_file: `references/project-design.md`

### 4. project_implement
Implement the designed project with production-quality code, documentation, and showcasing potential.
reference_file: `references/project-implement.md`

## Principles
### 1. The project is highly relevant to the target role
### 2. The project addresses a clear, real-world problem
### 3. The project demonstrates technical depth and innovation
### 4. The system is a complete, end-to-end solution—resembling a product ready for actual deployment
### 5. Project outcomes are quantifiable and evaluable
### 6. Stand on the shoulders of giants; avoid repetitive work; projects must be innovative
