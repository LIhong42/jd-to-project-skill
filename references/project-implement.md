# Project Implementation

Implement the designed project with production-quality code, documentation, and showcasing potential.

## Implementation Principles

### 1. Prioritize the implementation of the evaluation framework and optimize the project under its guidance.
### 2. The project is complete, runnable, and verifiable.
### 3. Complete documentation is provided, with the README available in both Chinese and English.
### 4. In addition to a simple README, it is also necessary to include a detailed project description document `detailed-explanation.md` that documents in detail the problems solved by the project, the algorithms and technical principles used in the project, as well as the project effectiveness evaluation methods and results. This report should be detailed, easy to understand, and enable non-technical personnel to quickly understand the role and effectiveness of the project
